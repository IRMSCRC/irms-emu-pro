# Code de conduite

Ce projet réunit des passionnés de simulation automobile de tous niveaux. Pour que chacun puisse y participer :

- Reste courtois, y compris en cas de désaccord technique. Critique le code ou l'idée, pas la personne.
- Accueille les débutants : une question simple mérite une réponse simple.
- Pas de harcèlement, d'insultes, de propos discriminatoires ni de publication d'informations personnelles d'autrui.
- Reste dans le sujet du projet.

Les responsables du dépôt peuvent modifier ou supprimer les contributions qui ne respectent pas ces règles et, en cas de récidive, bloquer leur auteur.

Pour signaler un comportement : contacte les responsables du dépôt par les moyens indiqués sur leur profil GitHub. Les signalements sont traités de façon confidentielle.

Ce texte s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
